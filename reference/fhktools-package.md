# Robust Foster-Haltiwanger-Krizan Productivity Decompositions

fhktools provides defensive implementations of the standard
Foster-Haltiwanger-Krizan (FHK) productivity decomposition. It
emphasizes auditable data choices, explicit turnover interpretation, and
exact accounting identity checks.

## Details

The main entry points are
[`fhk_decomposition()`](https://jingyiyiyiyi.github.io/fhktools/reference/fhk_decomposition.md)
for one endpoint pair,
[`fhk_adjacent()`](https://jingyiyiyiyi.github.io/fhktools/reference/fhk_adjacent.md)
for consecutive observed periods,
[`fhk_hierarchical()`](https://jingyiyiyiyi.github.io/fhktools/reference/fhk_hierarchical.md)
for economy-wide plus within-group results, and
[`fhk_multi_measure()`](https://jingyiyiyiyi.github.io/fhktools/reference/fhk_multi_measure.md)
for comparable results across several productivity measures.
