# A Deliberately Complex Synthetic Firm Panel

A teaching dataset derived from `fhk_example`. It contains an industry
mover, a zero-weight row, a missing alternative productivity value, and
a group observed at only one endpoint. It is intended for demonstrating
explicit audit policies, not for a default one-line decomposition.

## Usage

``` r
fhk_complex_example
```

## Format

A data frame with 21 rows and the same 10 variables documented in
[`fhk_example`](https://jingyiyiyiyi.github.io/fhktools/reference/fhk_example.md).

## Source

Generated by `data-raw/generate_example_data.R`.

## Examples

``` r
data(fhk_complex_example)
subset(fhk_complex_example, employment == 0 | is.na(productivity_alt))
#>    firm_id year      industry productivity productivity_alt employment

#> 14       H 2011      Services         3.00               NA         55

#> 14    0.1222222             0.2037037              2011             2015
```
